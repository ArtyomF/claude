# yandex-wordstat

Скилл для получения статистики поисковых запросов Яндекса без ручного захода на wordstat.yandex.ru.

## Что делает

- `scripts/popular_queries.sh "<фраза>" [регион_id]` — частотность фразы + похожие запросы + запросы, которые также искали
- `scripts/regions.sh "<фраза>"` — распределение спроса по регионам РФ
- `scripts/dynamics.sh "<фраза>"` — динамика запроса по неделям/месяцам (если доступно в отчёте)

## Как это работает технически

Wordstat не имеет собственного публичного API — отчёты генерируются через устаревший
**Yandex Direct API v4** (JSON, `https://api-sandbox.direct.yandex.ru/live/v4/json/` для песочницы,
`https://api.direct.yandex.ru/live/v4/json/` для боевого режима), методами:

1. `CreateNewWordstatReport` — ставит отчёт в очередь, возвращает `ReportID`
2. `GetWordstatReport` — забирает готовый отчёт по `ReportID` (не готов сразу — нужен poll с паузой)
3. `DeleteWordstatReport` — чистит отчёт после получения (хорошая практика)

⚠️ **Важно:** доступ к Wordstat-методам в Direct API выдаётся модерацией Яндекса отдельно от
обычного доступа к рекламному кабинету. Без одобрения запросы будут возвращать ошибку доступа.
Подайте заявку через форму в личном кабинете Директа или обратитесь в поддержку Яндекс.Директа.

⚠️ Пути эндпоинтов и формат ответов могут измениться — перед боевым использованием сверьтесь
с актуальной документацией: https://yandex.ru/dev/direct/doc/reports/wordstat.html

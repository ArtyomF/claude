# claude-yandex-skills

Набор скиллов для **Claude Code** — работа с Яндекс.Wordstat, Директ, Метрикой, Вебмастером
и Search API прямо из чата с Claude Code, без ручного захода в каждый сервис.

Собрано для проекта КОНИКС (konix.su), но скиллы универсальны для любого сайта.

## Состав

| Скилл | Что делает |
|---|---|
| `yandex-wordstat` | Частотность запросов, похожие фразы, регионы |
| `yandex-direct` | Кампании, объявления, статистика показов/кликов |
| `yandex-metrika` | Визиты, конверсии, отчёты по UTM-меткам |
| `yandex-webmaster` | Переобход страниц, статус индексации, ошибки сканирования |
| `yandex-search-api` | Проверка позиций сайта в выдаче Яндекса |

## Установка

```bash
# Глобально для всех проектов Claude Code
cd ~/.claude/skills
git clone https://github.com/ArtyomF/claude.git yandex-skills
# Переместите нужные папки yandex-* прямо в ~/.claude/skills/
mv yandex-skills/yandex-* .
rm -rf yandex-skills
```

Или для конкретного проекта:

```bash
cd ~/your-project/.claude/skills
git clone https://github.com/ArtyomF/claude.git yandex-skills
mv yandex-skills/yandex-* .
rm -rf yandex-skills
```

## Настройка токенов

**Каждый скилл настраивается отдельно.** Зайдите в `yandex-<name>/config/README.md` —
там пошаговая инструкция именно для этого сервиса.

Коротко:

1. Скопируйте `config/.env.example` → `config/.env` внутри нужного скилла
2. Заполните токены по инструкции из `config/README.md`
3. `config/.env` уже в `.gitignore` — не попадёт в git по ошибке

## Важная оговорка

Эндпоинты и форматы ответов Яндекс.API могут меняться. Скрипты написаны по документации на
момент сборки (сентябрь 2026) — если что-то не работает, первым делом проверьте актуальность
пути эндпоинта в официальной документации (ссылки есть в каждом `SKILL.md`).

## Использование в Claude Code

После установки Claude Code сам подхватывает скилл по описанию в `SKILL.md`, когда промпт
соответствует его назначению:

```
«посмотри в Wordstat спрос на "денник для лошади купить"»
→ сработает yandex-wordstat

«сколько заявок было с Яндекс.Директа за неделю по UTM»
→ сработает yandex-metrika

«попроси переобход новой статьи в Вебмастере»
→ сработает yandex-webmaster
```

## Структура скилла

```
yandex-<name>/
├── SKILL.md              ← манифест с триггерами и описанием
├── .gitignore
├── config/
│   ├── .env.example      ← шаблон переменных
│   └── README.md         ← как получить токены именно для этого сервиса
└── scripts/
    ├── common.sh          ← общие хелперы (загрузка .env, проверки, логирование)
    └── <action>.sh        ← конкретные действия
```

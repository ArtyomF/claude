# yandex-direct

Скилл для работы с Яндекс.Директ API v5.

## Что делает

- `scripts/list_campaigns.sh` — список кампаний аккаунта
- `scripts/get_ads.sh <campaign_id>` — объявления в кампании
- `scripts/create_ad.sh <campaign_id> <ad_group_id> <title> <text> <href>` — создать текстовое объявление (черновик, требует ручной проверки перед запуском)
- `scripts/get_stats.sh <campaign_id> <date_from> <date_to>` — статистика по кампании (отчёты через Reports API)

## Важно

Direct API v5 работает по JSON, эндпоинт: `https://api.direct.yandex.com/json/v5/<service>`
(например `/campaigns`, `/ads`, `/adgroups`, `/reports`).

⚠️ Создание объявлений через API — необратимое действие с реальными деньгами рекламного счёта.
Скрипт `create_ad.sh` создаёт объявление в статусе черновика/на модерации, но не запускает показы
автоматически — включение показов (изменение статуса кампании) делайте осознанно, вручную
проверив параметры.

⚠️ Проверьте актуальные эндпоинты перед использованием: https://yandex.ru/dev/direct/doc/dg/concepts/about.html

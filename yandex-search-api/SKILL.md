# yandex-search-api

Скилл для получения поисковой выдачи Яндекса программно через Yandex Cloud.

## Что делает

- `scripts/search.sh "<запрос>"` — получить топ выдачи по запросу. Автоматически:
  1. Создаёт асинхронную задачу поиска
  2. Дожидается готовности результата (polling)
  3. Распаковывает base64-XML и отдаёт чистый JSON-список: позиция, домен, url, заголовок
- `scripts/check_position.sh "<запрос>" "<домен>"` — найти позицию конкретного домена в выдаче
- `scripts/parse_results.py` — отдельный парсер XML→JSON, можно переиспользовать самостоятельно

Требуется **python3** в PATH — используется для разбора XML-ответа Yandex Search API
(стандартная библиотека, без внешних зависимостей). Если python3 не найден,
`search.sh` выведет предупреждение и покажет необработанный base64-ответ вместо ошибки.

## Настройка

Понадобится сервисный аккаунт в Yandex Cloud (не обычный аккаунт Яндекса) — это отдельная
регистрация с привязкой платёжного аккаунта, сервис платный (тарификация за количество запросов).

См. `config/README.md`.

⚠️ Проверьте актуальную документацию перед использованием, включая формат ответа
(результаты приходят в base64-encoded XML): https://yandex.cloud/ru/docs/search-api/

# yandex-webmaster

Скилл для Яндекс.Вебмастер API v4.

## Что делает

- `scripts/recheck_url.sh <url>` — поставить URL в очередь на переобход
- `scripts/recrawl_quota.sh` — остаток квоты на переобход за сутки
- `scripts/site_summary.sh` — общая сводка по сайту (проиндексировано страниц, ошибки)

## Настройка

См. `config/README.md`. Сайт должен быть добавлен и подтверждён в Яндекс.Вебмастере заранее —
это делается один раз вручную через веб-интерфейс webmaster.yandex.ru.

⚠️ Проверьте актуальность эндпоинтов: https://yandex.ru/dev/webmaster/doc/dg/concepts/about.html
